# LPをCloudflareで公開する手順

このフォルダ（`lp/`）の `index.html` 1枚で動く静的サイトです。ビルドの作業は要りません。

## 1. 公開前に差し替える箇所（必須）

`index.html` をテキストエディタで開き、次の文字列を置換してください。

| 置換する文字列 | 差し替える内容 | 出てくる回数 |
|---|---|---|
| `FORM_URL` | 外部フォームのURL（Googleフォーム、Tallyなど） | すべて（冒頭のコメント行を含め7か所） |
| `KINDLE_URL` | Kindleの著者ページ、または見本にする作品のURL | すべて（冒頭のコメント行を含め2か所） |
| `Rinen Studio` / `Rinen` / `Studio` | ブランド名を決めたら差し替える（ロゴ、タイトル、フッター） | 数か所 |

**数値の出典を確認してください。** 問題提起の欄にあるGallupの3つの数値（27%、12%、20%）は、作成時に検索結果の要約でしか確認できていません。公開する前に、リンク先で数値が合っているかを確かめてください。

## 2. Cloudflareへのアップロード（ダッシュボードの「Direct Upload」）

1. Cloudflareのダッシュボードにログインする
2. 左のメニューから **Workers & Pages** を開き、**Create** を押す
3. **Pages** タブで **Upload assets**（直接アップロード）を選ぶ
4. プロジェクト名を付ける（例：`rinen-studio`）。`https://rinen-studio.pages.dev` のような仮のURLが発行される
5. `lp` フォルダごとドラッグ＆ドロップして **Deploy site** を押す
6. 発行されたURLで表示を確認する（スマホでも見る）

> ダッシュボードの画面構成は、Cloudflare側の変更で名前や場所が変わることがあります。見つからないときは「Cloudflare Pages direct upload」で公式ドキュメントを確認してください。

## 3. 持っているドメインをつなぐ

1. 作成したPagesプロジェクトの **Custom domains** を開き、**Set up a custom domain** を押す
2. 持っているドメイン（例：`example.com` や `www.example.com`）を入力する
3. そのドメインのDNSが同じCloudflareアカウントで管理されていれば、DNSレコードは自動で追加される
4. 数分〜数十分で、`https://` のアドレスで表示されるようになる

## 4. 公開後にやること

- LinkedInとX（旧Twitter）のプロフィールにURLを載せる
- 外部フォームから送信テストをして、通知メールが届くか確認する
- Cloudflareの **Web Analytics**（無料）を有効にして、訪問数を測る
- 事例ができたら「See our manga」の欄に作品画像を追加する（画像は `lp/` に置き、`<img src="ファイル名">` で読み込む）

## 5. サンプルマンガ（Run After 40）の画像を載せる

1. `lp` の中に `sample` フォルダを作る
2. 8ページ分の画像を `p1.webp`〜`p8.webp` という名前で入れる（幅1200px、縦横比2:3を推奨）
3. 手順2と同じように、`lp` フォルダごと再アップロードする

画像がないページは「Coming soon」と表示されます。脚本と画像プロンプトは `../sample_run-after-40/` にあります。
