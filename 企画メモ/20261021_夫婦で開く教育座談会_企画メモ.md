# 夫婦で開く教育座談会 企画メモ

> 作成日：2026年10月21日
> 会場：コミュニティセンター／公民館の無料会議室（予定）
> 開催時期：2027年1月・2月の2回（予定）

## 結論

企画は実現できる。壁は次の2つ。

1. **会場のルール**：参加費の徴収、団体登録、予約の受付時期
2. **最初の参加者集め**：初回の5〜8人をどう集めるか

1〜2月に開くなら、**会場への確認と予約は11月中**に済ませる必要がある。施設によっては、1月分の受付がすでに始まっている。

## 1. 会場に確認すること（10月中〜11月上旬）

窓口か電話で、次の6点を聞く。

| 確認項目 | 理由 |
| --- | --- |
| 団体登録が必要か | 無料で借りられるのは登録団体だけ、という施設が多い。会員2人以上と簡単な規約で登録できるところもある |
| 参加費（お菓子代300円）を集めてよいか | 営利目的を禁じる施設が多いが、実費の徴収なら認められることがほとんど。「お菓子代の実費です」と伝え、収支を記録しておく |
| 予約の受付開始時期と方法 | 「2〜3か月前から抽選」の施設もある |
| 飲食してよいか | お菓子を出すので必ず確認する |
| チラシを掲示・配布できるか | 館内に掲示できれば、それがいちばん効く集客になる |
| 子ども連れで参加できるか | 隣の部屋や和室も借りられるかで、参加しやすさが大きく変わる |

> [!tip] 窓口で企画の趣旨も話してみる
> センターによっては共催・後援になってくれたり、広報紙に載せてくれたりする。社会福祉協議会や子育て支援センターへの相談も有効。

## 2. スケジュール（開催日からの逆算）

| 時期 | やること |
| --- | --- |
| 10月末〜11月中旬 | 会場の確認・団体登録・日程の仮押さえ（1月・2月の2回分） |
| 11月中 | 会の名前・テーマ・チラシを決める |
| 12月上旬〜 | 告知開始（年末年始は反応が鈍いので早めに出す） |
| 1月 | 第1回（参加者の目安は5〜8人） |
| 2月 | 第2回（第1回の参加者に、知り合いを連れてきてもらう） |

2回分をまとめて押さえるのがポイント。1回きりの会より、続く場のほうが人は来やすい。2回目は口コミで集まる。

## 3. 最初の5〜8人の集め方

効きやすい順に。

1. **直接声をかける**：保育園・幼稚園・学校の保護者仲間や近所の人に「夫婦でこういう会をやるので、来てくれない？」と個別に誘う。これがいちばん確実
2. **施設への掲示・設置**：センター館内の掲示板、子育て支援センターや児童館のチラシ置き場
3. **地域の連絡網**：LINEオープンチャット、自治会の回覧板（使えるかは自治会長に相談）
4. **SNS**：インスタグラムなど。顔の見える夫婦が主催していることが安心材料になる

### チラシに入れること

- **テーマは1つに絞る**：「教育の悩み全般」より「小学生の家庭学習、どうしてる？」のほうが人は来る
- 誰向けか（例：未就学児〜小学生の親）
- 子連れで参加できるか
- 「話さなくても、聞くだけでOK」の一言（これで参加のハードルがぐっと下がる）
- 申込方法（Googleフォームなど）と定員

## 4. 当日の流れ（90分の例）

| 時間 | 内容 |
| --- | --- |
| 0:00〜0:05 | あいさつ、グラウンドルールの共有 |
| 0:05〜0:20 | 夫婦の対談：わが家の悩みと、試したこと・失敗したこと |
| 0:20〜0:35 | 参加者の自己紹介と「今の困りごと」をひと言ずつ（付箋に書いてもらってもよい） |
| 0:35〜1:15 | 付箋をテーマごとに分けて雑談：「うちはこうしてる」「こんなことができそう」 |
| 1:15〜1:30 | 今日の気づきを1人ひと言、次回の案内、アンケート |

**対談のコツ**：最初に夫婦の失敗談や本音を出す。うまくいった話より、うまくいかなかった話のほうが場はほぐれ、参加者も話しやすくなる。

### グラウンドルール（冒頭で必ず伝える）

- ここで聞いた話は外に持ち出さない
- 否定しない。アドバイスを押しつけず、「うちはこうだった」という形で話す
- 話したくないことは話さなくていい
- 宗教・政治・商品の勧誘は禁止

## 5. 見落としやすい注意点

- **重い相談への備え**：不登校、発達の悩み、虐待が疑われる話などは、素人の会では受け止めきれない。市の子育て相談窓口や教育相談の連絡先を紙1枚にまとめ、配れるようにしておく。これがあるだけで場の信頼が上がる
- **お金の扱い**：お菓子代はレシートと参加人数を記録すれば十分。余りは次回に繰り越す
- **写真・SNS投稿**：参加者の顔を載せるなら必ず同意を取る。後ろ姿や手元だけにするのが無難
- **夫婦の役割分担**：1人が進行、もう1人が記録と子どもの見守り。事前に決めておけば当日慌てない
