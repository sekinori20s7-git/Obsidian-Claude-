## 6. 構成テンプレート（そのまま真似できる骨組み）

### A. 価値提供型（いちばん学ぶべき型）
1. 共感：悩みを箇条書きで代弁する
2. 問題提起：「でも、本当の原因は〜」
3. 体験談・比喩：ライオンとアンテロープ、一本足の椅子、家と銀行口座
4. 問題の置き換え：罫線で囲んだ一文（「〜ではなく、〜の問題です」）
5. 具体例・数字
6. 教訓
7. ワーク：「今週、一つだけ」「三つだけメモしてください」
8. 結び：冒頭の問いに戻る（円環）＋決まり文句
9. 追伸：ここで初めて商品にふれる（または問いを1つ残す）

> 手本：「野ネズミ作業の要注意」（2026/4）、「（保存版）外貨を『買う人』と『稼ぐ人』の違い」（2026/7）、「AI時代の運気のカラクリ」（2026/9）、「心の残高を操る極意」（2026/10）

### B. ストーリー型
1. 場面から入る（会話劇・旅先・家族）
2. 意外な展開・オチで笑わせる
3. 気づき → 教訓
4. 次回予告で連載化（「（続く）」「次回は〇〇」）

> 手本：「親友の数＝幸福？」（2024/8、妹との会話劇）、「僕の後悔リスト」（2025/9）、兄妹と父の寓話（2025〜2026に複数回）

### C. ティザー予告型
1. 「グッドニュースです」でイベントの存在だけを先に出す
2. 本題は価値提供（読む価値がある回にする）
3. 「申込はまだ受け付けていません」と明言する
4. 募集開始の日時を予約させる（「〇月〇日のメールだけは見逃さないで」）
5. 追伸で宿題（当日までに考えておくこと）

> 手本：「【X-DAY決定】超自動化術」（2026/11）、「【11月27日・特別開催】米国クレカ完全ウラ話。」（2026/10、リンクなしの純ティザー）

### D. 募集開始型
1. 「約束の時間になりましたので」で予告を回収する
2. 冒頭にリンク
3. なぜ今か（ニュース・円安・人口減などの背景）
4. 中身の特徴1〜4（罫線ボックス）
5. 特典を「〜相当」で列挙
6. 末尾に同じリンク（冒頭と末尾で挟むサンドイッチ）

### E. 締切リマインド型
1. 期限と残り時間を1行目に置く
2. Q&A形式で迷う理由をつぶす（「経験がなくても大丈夫？」「なぜ有料？」）
3. クレームや批判を逆手に取る（「『結局、金目当てかよ！』」）
4. 実話・感動話で売り込み感を消す（「ハワイでのヤバイ奇跡」）
5. 希少性（残り〇名・録画なし）→ リンク → 「何卒、お早めに」

### F. 超短文型（動画・音声紹介）
- 本文2〜5行＋リンク1本。追伸のほうが長いこともある。見どころをタイムスタンプで示す回もある

## 7. 販売シリーズの流れ（典型パターン）

ほぼすべての企画が、次の段階を件名で明示しながら1〜3週間かけて進む。

```
ティザー（謎・予告）→ 日時の予約 → 無料ウェビナー/LIVE → 「約束の時間」に募集開始
→ 特典の紹介 → 申込殺到（社会的証明）→ Q&Aで反論処理 → 特典消滅間際
→ 残り〇時間 → 最終案内 → 完全消滅 →（延長戦・再募集）→ 会員フォロー
```

実例：
- 外貨獲得スクール（2025/1〜2）：予告 → 残り日数のカウントダウン → 募集開始（80%OFF）→ 申込殺到 → 値上げ前の締切 → 第2弾 → 無料トークライブで集客 → 締切延長 → 「完全締切」の延長戦（最終日は1日3通）
- 潜在意識マスタリー2025（ブラックフライデー）：予告 → 無料プレゼントで温める → 募集開始 → 弱みの開示（不安症の遺伝子）→ リマインド → 実話の奇跡 → FINAL CALL → 本日完全終了
- THE AUTOMATION（2026/11）：謎の友人 → リスト別の予告 → 招待状 → X-DAY決定（募集開始日だけを告知）

**並走の工夫**：複数の企画が同時に動くときも、その合間に販売ゼロの価値提供メールやストーリー（購入者向けのMRM連番など）を挟み、信頼を回復させている。

## 12. 真似するときの注意

- **煽りの強さは割り引いて真似る**：「完全消滅」「今世紀最大」「90%OFF」の連発や、締切を延長して再度煽る手法は、受け手によっては不信感につながる。また、実在しない元値の表示や過度な効果の断定は、景品表示法などに抵触するおそれがある。型は構造だけ借り、表現は自分の誠実さの範囲に収める。
- **本文の使い回しが多い**：同じ本文を件名と冒頭だけ替えて再送している例が多数ある。学習では、同じ本文に別の件名をつけた比較の教材として使える。
- **表記ゆれ**：X-DAYメールでは募集開始日が「11月21日」「11月20日」の2通りで書かれていた。自分で書くときは、日付・数字・リンクを最後に必ず確認する。
- **転載しない**：真似るのは構成と型まで。文章は自分の言葉で書く。
