# 接点ログ（外国人との会話記録）

関連: [[20261020_外貨プロジェクト計画書]] ／ [[英語インタビュー質問集]]

> 形式は、セミナー第11章の「フィードバックを受ける前に、五つだけまとめる」をそのまま使う。
> **相手の言葉はそのまま（英語のまま）書く。** 要約や翻訳をすると、商品の説明文に使える言葉が消えてしまう。

## 集計（週末に更新）

|----------|------------|--------------------------|

## テンプレート（1人につき1ブロックをコピーして使う）

```
### #0X｜YYYY-MM-DD｜場所（例：オンライン英会話／Reddit／対面）

1. 誰と関わったか
   - 国・地域：
   - 訪日経験：なし／1回／2回以上（直近：YYYY年）
   - 関心（アニメ・食・自然・買い物など）：
   - 旅の形（一人／カップル／家族／友人）：

2. 何を試したか
   - 質問した／見本を見せた（どの案か）／その他：

3. どんな反応があったか（相手の言葉そのまま）
   - "　"
   - "　"
   - 行動（保存した・リンクを聞いた・購入した 等）：

4. 何がまだわからないか
   -

5. 次に何を変えたいか（1つだけ）
   -
```
