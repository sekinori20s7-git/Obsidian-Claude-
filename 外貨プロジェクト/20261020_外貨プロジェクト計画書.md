## 3. 30日のゴール（成果の定義）

**メイン（行動）**
- 外国人（訪日経験者・訪日予定者）**8人**と話す
- 相手が実際に使った言葉（verbatim）を**20個**記録する

**サブ（販売・接点）**
- Etsyの訪問を**週20以上**にする（集める方法を1つに絞って試す）
- CJG-PR-S3 の出品を**1か所だけ**直す（会話で出た言葉を反映）

**見るだけ（新しい作業はしない）**
- 『Run After 40』英語版の月間販売・既読ページ数（KENP）を [[週次トラッカー]] に記録する

> 「売上」は30日のゴールにしない。セミナー第11章の補足どおり、短期の売上は約束しない。購入があればボーナス。

## 4. 時間の使い方（週3〜6時間の固定枠）

| 枠 | 時間 | やること |
|----|------|----------|
| 平日A（例：火 朝） | 60分 | オンライン英会話などで外国人と話す（1人目） |
| 平日B（例：木 朝） | 60分 | 外国人と話す（2人目）。またはReddit等で読む・答える |
| 週末C（例：土 朝） | 60〜90分 | 接点ログの整理 → 気づいたことを1つ → 小さな改善1つ |
| 日曜D | 15分 | [[週次トラッカー]] を埋める |

**最低ライン（忙しい週）**：A＋D だけ（約75分）。0にはしない。

**減らすもの**（セミナー第2章「足すなら減らす」）：CJGの新しいSKU制作、Kawaii A の作り込み、画像の作り直しは**30日間凍結**する。

## 5. 週ごとの行動計画

### W1（10/21〜10/27）｜優先順位と目的を決める
- [ ] 外貨に取り組む理由を一文で書く（下の §9 に記入）
- [ ] 家族・仲間1人に宣言する（「11/19までに外国人8人と話す」）
- [ ] §4 の固定枠をGoogleカレンダーに登録する

- [ ] 会話の場を1つ選ぶ（例：いま使っている／試せるオンライン英会話。講師は訪日経験がある人を優先）
- [ ] **1人目と話す** → [[接点ログ]] に記録
- 手元に残すもの：目的の一文、カレンダーの予定、ベースラインの数字、会話1件

### W2（10/28〜11/3）｜実際の相手に触れる
- [ ] 2人と話す（累計3人）。[[英語インタビュー質問集]] のPart A〜Cを使う
- [ ] Redditの r/JapanTravel など：**宣伝はしない**。質問を読んで、よくある困りごとの言葉を5個メモする（各サブレディットのルールを先に確認）
- [ ] 「同じ困りごとを2人以上が言ったか」を確認する
- 手元に残すもの：会話3件、verbatim 10個

### W3（11/4〜11/10）｜複数の案を小さく試す（ドライテスト）
- [ ] 2人と話す（累計5人）。Part Dでカードの見本を見せ、**どれが欲しいか**を聞く
  - 見せる案（例）：①今あるRecap 3枚（靴・電車・温泉）／②会話で一番出た困りごとのカード（**案の段階**と伝える）／③Kawaii Aの表紙だけ
- [ ] 出品を1か所だけ直す（タイトル・1枚目の画像・説明の冒頭のどれか）。**何を変えたかを記録する**
- [ ] 集客の方法を1つだけ選び、週3回試す（Pinterest、TikTokを1本、Redditで役に立つ回答をする、のどれか）
- [ ] 金融の土台を確認する（§7 のチェックリスト）
- 手元に残すもの：案ごとの反応、変更した点とその日付

### W4（11/11〜11/17）＋ 振り返り（11/18〜11/19）
- [ ] 3人と話す（累計8人）
- [ ] [[接点ログ]] を見直し、困りごとの上位3つを書き出す
- [ ] §6 の判断基準で「続ける／直す／やめる」を決める
- [ ] 次の30日の一手を1つだけ決め、スクールのフィードバック・質問用に5つのまとめを書く
- 手元に残すもの：振り返りメモ、次の30日の一手

## 6. 判断基準（Day30）

| 状況 | 判断 |
|------|------|
| 同じ困りごとを**3人以上**が言った | その困りごとでカードを1枚作り、Etsyで試す（次の30日） |
| 困りごとがバラバラ | 対象者を絞り直す（例：初訪日／アニメ聖地巡礼／家族連れ）。次の30日も会話を続ける |
| 「マナーでは困っていない」が多数 | 前提が外れている。CJGの旗は残し、扱うテーマを実際に困った場面（交通・予約・支払いなど）に切り替える |
| Etsyの訪問が週20未満のまま | 商品ではなく集客の問題。試していない集客方法を1つ選んで、次の30日で試す |
| 訪問はあるのにお気に入り0 | 1枚目の画像とタイトルを変える |
| お気に入りはあるのに購入0 | 価格の見せ方・中身のスクリーンショット・安心材料を直す |

**判断に使わないもの**：再生数だけ。褒め言葉だけ（「いいね！」は需要ではない。質問・申込み・購入の深さで見る＝セミナー第8章）。

## 7. 金融の土台（最小限。W3でまとめて確認）

外貨の「入口と出口」をつなぐ（セミナー第4〜5章）。新しい口座開設はこの30日の範囲外とする。

- [ ] **Etsy Payments**：入金先の口座と通貨、入金スケジュール、手数料を確認する
- [ ] **KDP**：ロイヤリティの受取方法（受取口座・通貨・支払いの基準額）を確認する
- [ ] **Wise**（持っている場合）：ログインできるか、二段階認証、本人確認の更新依頼の有無。日本で登録したWiseは原則として残高上限100万円相当（セミナー掲載時の補足より。実行時に公式ヘルプで再確認する）
- [ ] 外貨収入の記録：Etsy・KDPの月次明細を保存するフォルダを決める（申告の区分は税理士・税務署に確認。ここでは判断しない）
