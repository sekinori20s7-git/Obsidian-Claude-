## 3. 止まっている理由と再開方法

このセッションでは Google Drive コネクタしか使えず、Google ドキュメントのコネクタはオフだった。Drive では、作成済みファイルの中身を書き換えられない。

- ユーザーは「Docsコネクタをオンにする」を選んだ。ただし、オンになったことはまだ確認できていない。
- 再開時は、まず ToolSearch で Google Docs のツール（read_doc / update_doc など）が使えるか確かめる。
- 使える場合は、`google-workspace` スキルの `references/docs.md` を読んでから、既存のドキュメントに章を差し込む。**新しいファイルは作らない。リンクを変えないため。**
- 差し込む位置は「妻の役割の育て方」の章の後ろ、「法律とリスクの確認事項」の前。
- 手順：read_doc で `revisionId` を取る → writeControl を付けて update_doc → 読み返して確認。

## 5. 追加する章の下書き（ユーザーに提示済みの内容）

ユーザーの元の言葉：「家族の会話がうまれる仕組みを作りたい。例えば、あげたプレゼントは家族で話さないと使えないものとか、時間。あげた人が不要でも、家族にとっては嬉しいものとか。旦那さんが参加していれば、奥様へのプレゼント、子どもへのプレゼント」

### 章タイトル案
家族の会話が生まれる仕組み

### 三つのルール
1. 家族と話さないと使えない
2. もらった本人には要らなくても、家族はうれしい
3. モノより時間

### 流れ
もらう → 家に持ち帰る → 家族と開ける → 家族で使う → 次の練習で「家でどんな話になったか」を一言話す。これを繰り返す。

### みらいOneの普段の活動で使う案（1人1,000円前後、金額はすべて仮）
- 子ども用の手作り「完走メダル」。親が持ち帰り、子どもの首にかけてあげる
- 奥様（旦那様）への地元の焼き菓子
- 家族みんなで開ける「質問カード」（例：「今日パパは何km走ったと思う？」）
- 家族に渡す「時間チケット」（例：「家事を1回代わる」「公園で30分遊ぶ」）。0円で、走った本人が書く
- 走っている姿の動画。家族のLINEで開いて一緒に見る
- 年2回の「家族参加デー」

毎回1,000円だとクラブの負担が大きい。渡すのは入会時や10回参加などの節目にし、費用は会費か参加費に含める案にする。

### 柱一〜六での使い方
- 一　カロさんイベント：参加者が家族へのおみやげを持ち帰る（子どもへのメダル、配偶者への焼き菓子、家族で見る動画）
- 二　カロさんの本：読者特典として「家族と話すための質問カード」
- 三　YouTube：動画ごとに「家族で見て話すテーマ」を添える
- 四　海外ランナー：帰国後に家族と見る動画、子ども向けのおみやげ
- 五　家族事業：子どもが親を案内するプログラム、家族どうしで手紙を書く時間
- 六　セミナー：宿題「家族に今日の話を3分する」、家族同伴の割引

### 指標
- 家で家族と話をした参加者の割合（次の練習で一言聞く）
- 家族の参加人数
- 関川さん自身の家庭では、未来地図の指標「一番下の子の表情」とつなげる

### 注意
- カロさんイベントは外部協賛NG（カロさん側の事情）。地元の店の品を使う場合は、協賛ではなく購入にする。みらいOneの普段の活動なら、地元の店との提携も検討できる。
- 品物の値段はまだ調べていない。ドキュメントでは「仮」と書く。
